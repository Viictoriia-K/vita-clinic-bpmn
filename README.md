## Моделирование процессов записи на приём для сети клиник «Вита»

### О проекте

«Вита» — сеть клиник, которой нужно удобное приложение для пациентов с записью на приём к врачу.

В рамках проекта требовалось описать текущий процесс посещения клиники и спроектировать процесс с автоматизированной записью на приём.

---

### Задача

На основе интервью с администратором, пациентом и врачом смоделировать процесс AS-IS, описать состояния и разработать модель процесса TO-BE с записью на приём через приложение.

---

### Результат

- проанализированы интервью с администратором, пациентом и врачом;
- по материалам интервью смоделирован этап посещения врача в процессе AS-IS (BPMN);
- составлена диаграмма состояний в нотации UML State Machine: состояния, переходы и события;
- спроектирован процесс TO-BE в нотации BPMN с записью на приём через приложение;
- пересмотрены роли: в процессе TO-BE запись не требует участия администратора.

---

### Инструменты

BPMN · UML State Machine · draw.io
